# CodeStorm Hub - Portfolio Website

This repository contains the CodeStorm Hub portfolio built with [Next.js](https://nextjs.org/). The site is optimized for GitHub Pages using static export.

## 🚀 Development

- **Install dependencies:** `npm install`
- **Start dev server:** `npm run dev`
- **Run lint checks:** `npm run lint`
- **Export static build:** `npm run export`

## 📦 Deployment

GitHub Actions automatically builds and deploys the static site to GitHub Pages whenever changes are pushed to `main`.

## 📁 Project Structure

```
app/        # App Router pages and global styles
public/     # Static assets served by Next.js
```
